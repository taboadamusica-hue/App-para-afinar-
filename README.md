# Mis Facturas

App personal para crear y gestionar facturas. Es un único archivo: `facturas/index.html`.

## Cómo usarla
- Abre `facturas/index.html` en el navegador (o publícala con GitHub Pages y añádela a la pantalla de inicio del iPhone).
- **Ajustes**: tus datos fiscales, IBAN, logo, IVA/IRPF por defecto y prefijo de numeración.
- **Clientes**: alta y edición de clientes.
- **Plantillas**: 3 diseños (Clásica, Moderna, Minimalista), color de marca y conceptos guardados.
- **Facturas**: crear, duplicar, marcar como cobrada, buscar/filtrar, exportar CSV.
- **Ver / Imprimir PDF**: usa "Guardar como PDF" del diálogo de impresión.
- **Resumen**: facturado, IVA, IRPF, cobrado, pendiente y desglose por trimestre (útil para los modelos 303/130).

Los datos se guardan en el propio navegador (localStorage). Haz copias de seguridad desde Ajustes.
